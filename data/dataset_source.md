# Sumber Dataset

TrashNet direncanakan sebagai dataset awal, tetapi URL sumber asli, pemilik, lisensi,
tanggal akses, versi, jumlah gambar, dan modifikasi belum diverifikasi. Jangan menggunakan
atau mendistribusikan dataset sebelum audit tersebut selesai.

Foto lokal tambahan harus diambil atau diizinkan oleh tim, tidak menampilkan wajah, alamat,
nomor kendaraan, dokumen, atau informasi pribadi, dan dipisahkan dari data training bila
digunakan sebagai test lokal.
