# Model Lokal

Letakkan hasil ekspor model asli di `model/keras_model.h5` dan urutan kelasnya di
`model/labels.txt`. Jangan membuat file model kosong atau model dummy.

Kategori MVP yang diharapkan adalah `cardboard`, `glass`, `metal`, `paper`, `plastic`, dan
`trash`. Jumlah serta urutan label wajib sama dengan output model.
